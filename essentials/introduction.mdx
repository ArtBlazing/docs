The easiest way to trade on-chain. Cove provides a secure, fast, and feature-rich trading experience directly within Telegram.

## What is Cove?

Cove is a decentralized trading terminal built directly into Telegram. It replaces slow text commands with a fast, visual interface.

<CardGroup>
  <Card title="Gasless & Bridgeless" icon="gas-pump-slash" iconType="solid">
    Execute trades across any network instantly. No need to hold native gas tokens or manually bridge funds.
  </Card>
  <Card title="Unified Balance" icon="wallet" iconType="solid">
    Deposit USDC once. Trade any token on Ethereum, Solana, Base, BNB, and MegaETH from a single global balance.
  </Card>
  <Card title="Speed" icon="bolt" iconType="solid">
    Blazing fast transactions with optimized execution routing to consistently beat the mempool.
  </Card>
  <Card title="Non-Custodial" icon="shield-check" iconType="solid">
    Cove uses [Privy](https://www.privy.io/) to secure wallets in isolated enclaves, separate from the trading layer. This ensures Cove never directly interacts with your funds.
  </Card>
</CardGroup>
