A Cove wallet includes an EVM address and a Solana address. Each belongs to one [profile](/essentials/profiles).

Send `/wallets` or choose **Wallets**. The older `/accounts` command opens the same panel.

## Read the wallet list

| Mark or value | Meaning |
|---|---|
| ✅ | Selected for trading |
| ⭐ | Primary wallet |
| **Balance / Positions** | Spendable USDC / token holdings value |
| **Deployable (selected)** | Spendable balance across selected wallets |
| 🔁 / ✋ | Automatic bridging / manual approval |
| **Imported / Bought** | How the wallet was added |

## Create a wallet

<Steps>
  <Step title="Choose the profile">
    Open the intended profile in `/profiles`.
  </Step>
  <Step title="Create and configure">
    Send `/wallets` → **New Wallet**. Choose **Auto-bridge ✅** or **I'll decide each time ✋** when prompted.
  </Step>
  <Step title="Check selection">
    The new wallet appears with a name such as **Wallet 2**. Check its ✅ mark before trading; tap its row to change selection.
  </Step>
</Steps>

## Select trading wallets

Tap rows to include or exclude wallets. **Select all** includes eligible wallets in the profile. At least one must stay selected; **Deselect all** leaves one.

With several selected wallets, review [Split Total versus Per Wallet](/features/multi-wallet-trading) before buying.

## Edit a wallet

Open its **⚙️** menu.

| Action | Effect |
|---|---|
| **Rename** | Set a label up to 32 characters |
| **Set as Primary** | Receive incoming user transfers and reward payouts here |
| **Auto-bridge** | Change how other-chain stablecoins reach the trading balance |
| **Move to other profile** | Move the wallet with its positions, orders, and history |
| **Downgrade Smart Wallet** | Remove smart-wallet authorization on applicable chains; a later Cove trade may enable it again |
| **Delete Wallet** | Open secure management to remove Cove's access |

There is **one primary wallet across all profiles**. It cannot be deleted. Changing it while a reward payout is pending cancels the request; review the destination before requesting again.

Each profile holds up to **10 wallets**; the account-wide total is **160**, including archived and Paper wallets.
