Open **Settings → Position panel settings** for sell-link preferences. Filters and sorting are inside `/positions`.

## Sell links and confirmation

| Setting | Default | Effect |
|---|---|---|
| **Sell 100% Links** | Off | Add full-sell links to position rows |
| **Sell confirmation** | On | Ask before selling through Positions links |

**Sell confirmation** is profile-specific and separate from the trading panel's **Sell confirm**. Keep it on if you want to review a position-list sell before sending.

To change either, tap it and check the resulting on/off state. Reopen Positions to see the updated links.

## Filter your positions

1. Send `/positions` → **Filters**.
2. Select **Chains**, **Accounts** (wallets), or **Other**.
3. Toggle the categories you want to hide.
4. Use **Configure filters** for editable dust and liquidity thresholds.
5. Return to the list and review the result.

| Filter | Documented default |
|---|---|
| **Hide dust** | On |
| **Hide low liq** | On |
| **Hide suspicious** | On |
| **Hide natives & wrapped** | Off |
| Dust and low-liquidity thresholds | Read the saved values in Configure filters |

Do not assume the example values on a label are the saved thresholds. Filters hide rows; they do not sell tokens.

## Sort and hidden positions

**Sort** offers **Worth** (default), **Age**, and **PnL**. Filters and sorting are shared with the account's Mini App view.

Use **Hide** for an individual token and **View hidden** or the Mini App's **Hidden** list to **Unhide** it. If a holding is missing, check these filters and the active profile before assuming the balance is gone.
