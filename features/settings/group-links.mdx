Shared Cove links can open a token panel or request a fixed buy or percentage sell. The funds and positions belong to the person clicking the link.

Open **Settings → Group buy/sell** to control these actions.

## Set a group-buy limit

1. Open **Group buy**.
2. Choose **Off**, **\$100**, **\$500**, **\$1,000**, **\$5,000**, or **Custom**.
3. For Custom, follow the prompt; the supported maximum is **\$100,000**.
4. Review the new state and amount.

The documented initial setting is **Off**. When enabled, the amount is a cap for group-link buys, not an amount to spend on every click.

## Enable group sells

Open **Group sell** and toggle it on only if you want shared sell links to be able to act on your holdings. It is **off by default**.

A group sell applies the requested percentage to your own token position. When several wallets hold the token, a wallet picker may appear.

## How shared links behave

A panel-only link opens a token so you choose the amount. A group-buy link requests a fixed USD buy. A group-sell link requests a percentage of the clicker's holding.

New users complete onboarding first. A link does not create a holding out of nothing. While **Scam warning** is on, flagged panel-less group buys are refused.

The group-buy maximum and Group sell preference are account-wide; group-buy authorizations can follow the profile. Check the 👤 indicator in the current panel.

Group owners can set scan buttons and referral links in [Cove Buy](/groups/cove-buy). Builders can read [Deep links](/builders/deep-links).
