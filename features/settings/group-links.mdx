Group buy/sell settings control actions opened from a group, channel, or shared link.

## Group buy

Set a maximum instant group-buy amount. A buy above the limit asks for confirmation. Set the control to `Off` to disable group buys.

## Group sell

Group sell controls links that sell a percentage of your own position. The link does not sell a shared group wallet position.

For link formats and account behavior, see [Deep Links](/builders/deep-links) and [Cove Buy](/groups/cove-buy).
