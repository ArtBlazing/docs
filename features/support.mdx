Open **Contact** on the main menu or send `/support`.

## Create a ticket

<Steps>
  <Step title="Choose the request type">
    Select **Get Help** for a problem or **Send Feedback** for a suggestion.
  </Step>
  <Step title="Describe the issue">
    Include what you tried, what happened, the token/chain, and the profile involved. For a failed trade, forward its failure message with the reference.
  </Step>
  <Step title="Add an attachment if useful">
    Send a Telegram photo or a supported video up to **20 MB**. A caption becomes the message text.
  </Step>
  <Step title="Track the ticket">
    Check **Ticket created** and its number. Use **My Tickets** to view, reply, or close it.
  </Step>
</Steps>

## Screenshots and screen recordings

| Attachment | How to send |
|---|---|
| Screenshot/image | Send as a **Telegram photo**, not an image file |
| Video/screen recording | **MP4, MOV, or WebM**, as video or file |
| Size | Up to **20 MB per attachment** |

Use one attachment per message. Add more through **Add More Details** or by replying to a ticket notification. Trim an oversized recording before resending.

If attachments are temporarily unavailable, send the text first and add the attachment later.

## Information that helps

- The expected result and actual result.
- Approximate time, profile, wallet label, token, and network.
- The failure message and its reference.
- A screenshot of the complete error or a short recording.
- For a marketplace purchase: **Copy reference and open chat**.
- For a failed Private Disperse: **Get refund**.

<Warning>Never send private keys, seed phrases, agent tokens, import CSVs containing keys, or login codes. Crop or mask sensitive information in attachments.</Warning>
