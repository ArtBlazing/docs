Select `Contact` on the Cove home screen. The opened panel is titled `Support`.

<Frame><img src="/assets/current-ui/support-overview.png" alt="Current Cove Support panel with Send Feedback and Get Help actions" /></Frame>

## Send Feedback

1. Select `Send Feedback`.
2. Enter your feedback in the prompt.
3. Submit it and review the delivery receipt.

## Get Help

1. Select `Get Help`.
2. Send a text description or photo.
3. Review the support reply card when a response arrives.
4. Select `Reply` to continue the ticket.
5. Select `Close Ticket` when the issue is resolved.

<Frame><img src="/assets/current-ui/support-get-help.png" alt="Current Get Help prompt asking for a text description or photo" /></Frame>
