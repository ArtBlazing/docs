A multi-wallet trade acts on selected wallets in **one profile**, up to **10 wallets**. It does not combine wallets from different profiles.

## Set up a multi-wallet buy

<Steps>
  <Step title="Select the wallets">
    Open `/wallets` and tap the wallets you want to include. Check their ✅ marks and **Deployable (selected)**.
  </Step>
  <Step title="Open the token and wallet settings">
    Paste the token address. Open the wallet picker and its **Multi-account settings** or preferences.
  </Step>
  <Step title="Choose Spend type">
    Select **Split Total** or **Per Wallet**. Check the total cost before choosing the amount on the trading panel.
  </Step>
  <Step title="Set optional timing and variance">
    Review **Buy variance**, **Transaction delay**, and **Primary wallet first**, where offered.
  </Step>
  <Step title="Buy and check each result">
    Return to the panel, choose the size, and submit. The combined receipt shows success, actual spending, and failures per wallet.
  </Step>
</Steps>

## Split Total versus Per Wallet

For an illustrative **\$100** buy with **two wallets**:

| Mode | What the amount means | Example total |
|---|---|---|
| **Split Total** — default | One total divided between selected wallets | **\$100** across both |
| **Per Wallet** | Each wallet uses the full amount | **\$200** across both |

<Warning>In Per Wallet mode, adding wallets increases the combined amount spent. Check the count and mode before every buy.</Warning>

## Other settings

| Setting | Effect |
|---|---|
| **Buy variance** | Varies wallet-level amounts in Split Total mode; ignored in Per Wallet mode |
| **Transaction delay** | Spaces buys apart; offered choices include Off, 250 ms, 500 ms, 1000 ms, and Custom |
| **Primary wallet first** | Gives the primary wallet a head start when it participates |

Variance and delay apply to buys. Use the values offered in the current picker; it shows which custom inputs are accepted.

## Sell across wallets

Choose a sell percentage. Each selected wallet sells that percentage of its own holding. **\$-denominated sells are unavailable with multiple wallets**; use a percentage or select one wallet.

## Review wallet holdings

Expand the token panel's wallet details to compare each wallet's position and PnL. This is a holdings view, not the trade receipt.

## Check partial success

The receipt can report **Bought X/Y Successfully**. Review each wallet's actual spend and received amount. A **max-buy cap** note means the token limited the purchase below the requested amount.


Do not repeat the whole batch without checking successful wallets. Reopen the selection and retry only what still needs attention.

[DCA buys](/features/dca-orders) always split their total across wallets, regardless of Per Wallet mode. Use [Disperse/Collect](/features/transfers) to organize balances beforehand.
